# 完全分類アトラスの設計 — 2026-11-16 / v18

## 目的と現在の確実性

対象は標準14641型の四次元quadratic Koszul AS-regular indexed Z-algebra、
同値は添字保持同型とする。最終成果は族の羅列ではなく、
**全対象の被覆定理、各枝の正規形・全同型判定・特殊化関係**を備えた分類である。
以下は研究方法の設計であって、網羅的な場合分けや正則判定が証明されたという主張ではない。

標準Frobenius四周期の四窓表示では、各 V_i は4次元、各 R_i は
V_i⊗V_{i+1} 内の6次元関係空間であり、表示データは四つの
Gr(6,16) に属する。GL(V_0)×…×GL(V_3) が基底変更として作用する。
四窓へ還元できることと、この全表示空間内でAS正則locusを完全決定したことは別である。
標準4周期の選択、添字保持同型、周期構造付き同型を混同しない。

## 研究の主経路

1. **全体を固定する**：四窓のAS/Koszul必要十分条件を探し、既知の
   Frobenius有限条件と未解決のKoszul条件を区別する。
   構造定理を優先し、巨大な消去計算を最初から全空間へかけない。
2. **構造的な分類木を作る**：添字保持同型で不変なrank、テンソル分解、
   双対の中心・Nakayamaデータ、点/線スキームなどから枝を選ぶ。
   それぞれの切断条件と親枝の被覆（枝の和が親に等しいこと）を証明する。
   point scheme等は非完全不変量になり得るので同型の十分判定には使わない。
3. **枝ごとに正規形を与える**：有限型パラメータ空間、分母が非零という条件、
   特殊値、正則性、同型の残余群作用を明記する。
   一般パラメータの計算で零となった判別式の枝を捨てず、例外枝として記録する。
4. **同型を安く検査する**：計算の軽いGL不変量で候補を絞り、
   正規形の安定化群と許容変数変換を調べる。最後にだけ一般の
   212未知数388式の有限同型判定を使う。
   特徴量の不一致は除外証明となり得るが、一致だけで同型とはしない。
5. **特殊化を接合する**：パラメータの例外境界、他の正規形への基底変換、
   軌道閉包の包含、全正則locusにおける成分性を別々に証明する。
   ある族が別族の閉包に入っても、一般ファイバーの同型や成分一致を推論しない。
6. **証明されたデータから分類表を生成する**：本文の表を手入力の正本にしない。
   数学的証明がある枝だけ確定分類として表示し、未解決枝を明示する。

## 分類木と成果の最小単位

「1例」や「既知族」ではなく、**条件を持つ分類枝**を単位にする。
各枝に安定したIDを与える。少なくとも次の情報を管理する。

- 親枝と所属述語：親領域のどの部分を扱うか、選んだ不変量の同型不変性
- covering claim：親を子が覆うという主張、証明箇所、未証明ならその旨
- 正規形と基底：四窓の全関係式、パラメータ条件、分母、特殊値、入力源
- 正則性：全パラメータかgenericのみか、左右Koszul/AS証明、未解決除外領域
- 同型条件：必要条件と十分条件を分離し、許容変換と残余安定化群を記録
- 周期：最小周期1/2/4の証明された領域と判定不能領域を分離
- 交差と退化：他の枝への同型・包含・特殊化、正則性維持の条件と証明
- 検証：論文の定理ラベル、再現用入力・コード・証明書、文献と新規性の状態

状態は一つの「完了フラグ」にせず、
**構成、AS正則、被覆、同型必要十分、境界接合、周期、文献照合**
を独立の証明義務とする。例えば現行九変数族はAS正則・一般周期は証明済みだが、
全対象の被覆・成分最大性・完全同型は未完成である。
既知の結果を「分類済みの枝」と誤登録しない。

親枝の被覆は機械的な件数合計ではなく、数学的に
（親の各点はいずれかの子に属する）と証明する。
兄弟枝は重なってもよい。その場合は交差と同型条件を記載する。
分類木は包含・特殊化の有向グラフとは別に管理する。

## 計算と表の拡張方式

**今は新しい巨大な登録簿を作らない。** 現行の research/STATE.json は主張と
課題の索引として保持する。最初の非自明な「親を覆う」場合分けが証明された時点で、
その枝を最小の1件として記録し、必要なJSON schema・検査器・表生成器を導入する。
その時からデータを1枝1ファイルとし、原稿に同じ表を転記して手修正しない。

将来のレコードは例えば branch_id, parent_id, membership_condition,
parameter_scheme, normal_form_ref, regularity_ref, cover_ref,
isomorphism_ref, period_ref, boundary_edges, status_by_claim,
verification_refs とする。
式・定理・証明をJSONに複製せずTeXへの安定したラベルで参照する。
枝数やページ数に固定上限を置かない。

計算では、厳密な有理数・代数数を最終証明に使う。
有限体標本やランダム階数は候補発見・反例探索に使い、一般命題には
記号的小行列式、飽和イデアル、構造的証明などの証明書を付ける。
追加の枝だけ再計算するインクリメンタル検証とし、
既に証明済みの共通補題を毎回計算し直さない。
例外パラメータ（分母ゼロ、判別式ゼロ）を未分類のまま消去しない。

分類表は必要に応じて「短い公表用」「完全な検索用」の二表示を生成する。
論文は構造定理と代表的な族を理解しやすく示す本文を維持し、
大きな列挙は生成可能な表と証明参照で支える。
旧版・中間表・変更履歴・複製文献PDFは保持しない。

## 実際の着手と回帰試験

最初は四窓AS条件について、全対象に適用できる分岐不変量を一つ探し、
**分岐の網羅性の証明**まで追う。同時に量子多項式、Clifford点、
七・九変数楕円Ore族、五変数境界族、as4の最小周期4例を回帰試験入力とする。
これらを全分類の完成した枝と見なさない。
外部の4d-AS-regularデータベース（https://4d-as.ncag.info/）には
gradedの既知族が族単位で記録されているので比較・回帰に使えるが、
indexed Z-algebraの網羅性を保証しない。
比較時は必要な出典と参照箇所だけを保持し、外部全件を無批判に複製しない。

Codexは各作業で「どの未解決の被覆義務を減らすか」を決めて着手し、
局所計算が長引けば別の構造的不変量や枝へ自律的に切り替える。
現行の証明や反例は必要な箇所へ統合し、研究ノートは作業ログにしない。
再開時は research/plan_ja.tex → 本設計 → 未解決の枝 → 必要な証明だけ読む。
GitHub mainを正本とし、再現可能なソースだけを保存する。
