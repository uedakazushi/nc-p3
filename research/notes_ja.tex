\section{現在有効な知識と記法}
$C=(C_{ij})$を正連結な二次$\mathbb Z$-代数とする。
$V_i=C_{i,i+1}$，$R_i=\ker(V_i\otimes V_{i+1}\to C_{i,i+2})$と置く。
標準14641型では$\dim V_i=4$，$\dim R_i=6$。
$C(r)_{ij}=C_{i+r,j+r}$。
$\operatorname{Per}(C)=\{r\in\mathbb Z:C\simeq C(r)\}$は部分群であり、
標準14641型の左右AS双対性から$4\in\operatorname{Per}(C)$。
最小周期1、2、4が実例で実現し、周期を全閉ファイバーにわたり
一定と見なすことはできない（既存as4周期性論文を引用）。

\section{証明済み（ASZ4原稿）}
\emph{4周期同型の選択を保持する}二次代数の群oidは、
四頂点の$V_i,R_i$および$G=\prod_{i=0}^3\GL(V_i)$の作用群oidで記述できる。
ここで「厳密4周期的」な基底の選択を含む表現からの主張である。
証明全文は\texttt{papers/asz4\_classification.tex}の定理
\texttt{thm:four-window}とその証明。
Grassmannianのパラメータ全体がAS正則とは主張していない。
AS正則性の locus のscheme構造・開閉性も未証明。

\section{1周期・2周期の整合する対角表示（原稿で証明）}
選んだ4周期同型$\tau_4$が1周期同型$\sigma_1$の4乗なら、
四窓を同一生成空間に同定して$R_0=R_1=R_2=R_3$とできる。
$\tau_4=\sigma_2^2$なら$R_0=R_2,\ R_1=R_3$とできる。
逆にこれらの厳密対角表示は整合する周期同型を与える。
詳細な証明は原稿の命題\texttt{prop:compatible-periodic-windows}。
裸の$C$の周期性から、\emph{任意の}4周期同型$\tau_4$との
整合性が従うとは主張していない。
この点がgradedの1周期的対角軌跡と4周期全体を比較する
最初の重要な補正である。

\section{Koszul--Frobenius標準4周期と同型類の簡約（証明済み）}
\emph{最も重要な新しい構造結果。} 有限最小Koszul解消と左右AS双対性から
$E=C^!$の各$E_{i,i+4}$は一次元で、相補次数積が完全である。
非零trace $\lambda_i:E_{i,i+4}\to k$を選ぶと
\[
 \lambda_i(ab)=\lambda_j(b\nu^\lambda_{ij}(a))
\]
が$\nu^\lambda:E\to E(4)$を定め、二次双対に
$\tau^\lambda:C\to C(4)$を定める。
別のtrace $\lambda'_i=t_i\lambda_i$に対して
\[
 \nu^{\lambda'}_{ij}=(t_i/t_j)\nu^\lambda_{ij}.
\]
$s_{i+4}/s_i=t_i$を満たす非零$s_i$を四つの整数剰余類上の
再帰式で選び、頂点スカラー自己同型
$h_{ij}(a)=(s_i/s_j)a$とすると
$\nu^{\lambda'}=h(4)\nu^\lambda h^{-1}$。
二次双対でも同様の共役性が成り立つ。
さらに任意の$C\cong C'$はtraceを移送するので、
\textbf{裸の標準14641型Z代数の幾何学的同型類は、
Frobenius標準4周期同型付きの組の同型類に一対一に対応する。}
証明全文は原稿定理\texttt{thm:canonical-four}と系
\texttt{cor:canonical-slice}。群oidの同値・相対族上の下降は未証明。

\section{有限なtrace行列と周期判定（証明済み）}
四窓の二次双対について、四つの最高次traceを選び、
$E_{i,i+1}$の基底$u_a$、$E_{i+1,i+4}$の基底$v_b$、
厳密4移動した$E_{i+4,i+5}$の基底$u'_c$で
\[
 P_i=(\lambda_i(u_a v_b))_{a b},\qquad
 Q_i=(\lambda_{i+1}(v_b u'_c))_{b c}.
\]
局所中山同型の行列は$N_i=Q_i^{-1}P_i^\mathsf T$。
$\tau$がFrobenius標準であることは、適切な非零traceを選び
$P_i^\mathsf T=Q_i$を$i=0,1,2,3$で満たすことと同値。
原稿命題\texttt{prop:canonical-matrix}。

裸の$C$が$p$周期的であることは、Frobenius標準四窓で
四つの可逆$g_i:V_i\to V_{i+p}$（添字mod 4）が存在し
\[
 (g_i\otimes g_{i+1})R_i=R_{i+p}
\]
を満たすことと同値。証明の核心は、任意の$p$周期同型で
移送したFrobenius標準$\tau$とシフトした$\tau(p)$は
頂点スカラー共役であり、その補正により$p$周期同型を
4周期同型と可換に取れること。従って\emph{標準四窓に限って}
周期1/2/4を四つの有限多項式方程式とdet非零条件で判定できる。
原稿定理\texttt{thm:finite-period-test}と系
\texttt{cor:period-orbits}。まだこれを個々の族で消去してはいない。

四窓二次双対$E$の局所Frobenius条件自体は
長さ$0,\ldots,5$の次元と相補次数の対合行列の
階数という有限検査で認定できる。
$E_{i,i+5}=0$なら次数一生成性により全高次が零。
\emph{ただしKoszul性・AS正則性はこの有限検査から自動ではない。}
原稿命題\texttt{prop:finite-frobenius}。

\section{周期判定の明示的な多項式系と証明書}
四窓の$R_i$に階数6の列行列$M_i\in
\operatorname{Mat}_{16\times6}(k)$を選ぶ。
Frobenius標準4周期の場合、
$p=1,2$を判定する有限条件は
\[
 (G_i\otimes G_{i+1})M_i=M_{i+p}H_i,\qquad
 u_i\det G_i=1\quad(i\in\mathbb Z/4),
\]
$G_i\in\operatorname{Mat}_{4\times4}$、
$H_i\in\operatorname{Mat}_{6\times6}$、$u_i\in k$。
未知数は$4(16+36+1)=212$、行列等式は$4\cdot16\cdot6=384$
成分、可逆性は4式。
$G_i$の可逆性と$M_i$の階数6から$H_i$も可逆となる。
証明は原稿命題\texttt{prop:period-polynomial-system}。
全方程式の可解性を判定する作業と、
特定の$G_i$という\emph{正の証明書}を検証する作業は別である。

\texttt{computations/verify\_period\_witness.py}は
Fractionによる厳密階数計算で正の証明書をチェックする。
可換4変数多項式環の$p=1$の恒等行列、
AS4の$A(1)$の$p=2$の恒等行列、
$A(\lambda)(1)=A(-\lambda)$の表示恒等式はPASS。
$A(1)$の$p=1$に対する\emph{恒等行列の候補}はFAILしたが、
これは$p=1$の全候補がないという証明ではない。
その非存在はas4の点配置の証明に依存する。
コードとローカル実行ファイルのGit blob SHA一致を確認した。

\section{正確な有効群作用}
四つの関係空間のGrassmannianに作用する
$G=\prod_{i=0}^{3}\GL(V_i)$のうち、
各$V_i$のスカラー$(k^\times)^4$は\emph{全点}を固定する。
従って点集合の有効作用は$\prod_i\PGL(V_i)$に因子化する。
ただしstack/群oidにおける自己同型は消えない。
Grassmannian全体のdim240から有効群dim60を引いた180は、
AS正則モジュライの次元ではない。

\section{外積代数による明示検算}
可換多項式環$k[x_0,\ldots,x_3]$の双対は外積代数
$E=\Lambda(e_0,\ldots,e_3)$である。
最高次数$\omega=e_0e_1e_2e_3$に対するtraceを
$\lambda_i(\omega)=(-1)^i$と選び、次数三基底を
$v_b=(-1)^b\prod_{c\ne b}e_c$とすると
\[
 P_i=(-1)^i I_4,\qquad Q_i=(-1)^i I_4.
\]
従って$N_i=I_4$、厳密4移動は標準4周期となる。
一定traceなら$N_i=-I_4$であり、\emph{同じ代数でtraceの選択により
表示が変わる}ことに注意。
正確な全4頂点の計算は
\texttt{computations/verify\_exterior\_trace.py}にあり、
Python 3の分数計算でPASSした。これは一般のAS正則条件の
計算認証ではない。

\section{最重要の論理的落とし穴}
\begin{itemize}
\item $C\simeq C(4)$の存在と、$\tau_4:C\to C(4)$の指定の違い。
四窓の$\GL_4^4$商は$(C,\tau_4)$の分類であって、$C$単独の分類ではない。
\item 任意の1周期同型$\sigma:C\to C(1)$が、あらかじめ選んだ$\tau_4$と
可換するとは限らない。任意の4周期同型では、この可換性を先に要求すると周期1を見落とす。
Frobenius標準4周期同型なら、頂点スカラー共役によって
$p$周期同型を可換に補正でき、有限四窓の完全判定が可能である。
\item graded同型、Zhang twist同値、indexを忘れた同値、
qgr同値、導来同値は同一ではない。
\item Koszul双対の次元$(1,4,6,4,1)$、Frobenius完全対合、
PBW/低次数のHilbert値、全Koszul解消の正確性は異なる条件。
\item 点配置が隣接して異なれば1周期性を排除できるが、
点配置が同型でも関係テンソルが同型とは限らない。
\item 非1周期性を満たす一般点を持つ平坦族は、周期種別が
既約成分を切るとの推測への障害である。
\end{itemize}

\section{新たに証明すべき問題}
\begin{enumerate}
\item 四窓のKoszul/AS locus を有限条件で記述する：
どの全次数の解消exactnessが必要か、通常のFrobeniusだけで
足りるためのKoszul性仮定の具体化。
\item Frobenius標準4周期による幾何学的同型類の全単射を
相対族/モジュライstackの同値へ強化できる条件を調べる。
\item 有限四窓の周期可解性方程式を既存2周期/4周期族で消去し、
閉値の同型・例外・像のclosureと既約成分の関係を決める。
\item as4の2周期族$A(\lambda)$と4周期例を四窓に載せ、
全特殊値の同型・変形を調べる。周期性の非一致の
証明は\texttt{as4}の元原稿・コードから再利用する。
\end{enumerate}

\section{2周期例での添字移動の非同型性}
既存の$A(\lambda)$は、関係の唯一の添字依存が
$XZ+ZX=(-1)^i\lambda WY$なので、
\[
 A(\lambda)(1)=A(-\lambda)
\]
が表示上厳密に成立する。
しかし最小周期2の$\lambda$では
$A(\lambda)\not\simeq A(\lambda)(1)$なので
\[
 A(\lambda)\not\simeq A(-\lambda)
\]
である。特に既存の非1周期性証明がある$\lambda=1$で成立する。
論文の命題\texttt{prop:period-two-sign}を参照。
添字全体の平行移動を同一視する\emph{別の}moduliとの違いを明示する。
一般$\lambda,\mu$の同型条件は未解決。
